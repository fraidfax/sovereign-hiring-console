Architecture summary

This demo runs end-to-end on this machine using only the Python standard library — there is no cloud call, no external API, and no network egress for candidate data. The production target for this design keeps that same guarantee at scale: all components sit in an EU Azure region behind private networking (VNet + Private Link, no public endpoints), the scoring workload runs in confidential compute, encryption keys are customer-managed via Key Vault, and access is governed by Entra ID role-based access control with an immutable audit trail. Candidate data never leaves the organisation's own network boundary, in the demo or in production.

Bias Check

Computed server-side from the unredacted records, used only to prove the redaction did not leave a hidden gap between protected groups — never to re-identify or re-rank anyone.
